How this record is measured

Paper and live stay separate. Fill sessions count dates with completed trades; a no-fill report card can still appear in the journal. The paper balance is the $10,000 reset plus closed results, not a live account connection.

Dollar amounts add in integer cents. A settled value takes priority over a gross value. Only recorded R and initial-risk values are used. Missing values are never reconstructed. A missing legacy exit time is not an open position when its settled result proves it closed. No private trade notes or account identifiers are shipped.

Report grades are copied from the current card, never inferred from profit or missing records. A held review is labeled provisional. Publication of this website does not mark an end-of-day draft reviewed or release an X post.
